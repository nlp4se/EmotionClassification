# EmotionClassification

Finne-tuning to detect emotions from a reviews, based on the paper [What About Emotions? Guiding Fine-Grained Emotion Extraction from Mobile App Reviews
](https://arxiv.org/abs/2505.23452). Created two different files:

- binary-ensambler.ipynb -> Works for binary classification of each label
- multiclass-multilabel.ipynb -> Multiclass & multilabel algorithm


In the folders you can find the different results & predictions:

- Predictions -> in each folder there is the file for each fold execution
- Results
